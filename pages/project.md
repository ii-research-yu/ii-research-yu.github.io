### <a name="iir"></a>[Neural Interactive Information Retrieval](https://github.com/y-research/Neural_IIR)

#### About
This project (A Novel Interactive Information Retrieval System Using Deep Neural Network) is supported by the Japan Society for the Promotion of Science (JSPS), 2017-04 -- 2019-03.

PI: Hai-Tao Yu.

The target of this research is to develop enhanced techniques to improve the user-experience when users are browsing, searching and retrieving desired information.

- <a href="#ppir">Privacy-preserving IR</a>

### <a name="ppir"></a>[Privacy-preserving Information Retrieval](https://github.com/y-research/PPIR)

#### About
This project (A Scalable Privacy-preserving Information Retrieval System based on Federated
Optimization, On-device Intelligence and Semantic Matching) is supported by the Japan Society for the Promotion of Science (JSPS), 2019-04 -- 2023-03.

PI: Hai-Tao Yu.

This project aims to initiate research into privacy-preserving information retrieval and develop a scalable privacy-preserving IR system.
