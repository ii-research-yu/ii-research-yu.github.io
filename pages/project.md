### <a name="iir"></a>[Neural Interactive Information Retrieval](https://github.com/y-research/neural_iir)

#### About
This project (A Novel Interactive Information Retrieval System Using Deep Neural Network) is supported by the Japan Society for the Promotion of Science (JSPS), 2017-04 -- 2020-03.

PI: Hai-Tao Yu.

The target of this research is to develop enhanced techniques to improve the user-experience when users are browsing, searching and retrieving desired information.
